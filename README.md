# Calculadora Científica

Sitio de **calculadora científica online** para [calculadoracientifica.org](https://calculadoracientifica.org) en español de México.

## Incluye

- Calculadora científica web (trig, logs, potencias, DEG/RAD)
- Herramientas: trigonometría, grados↔radianes, notación científica
- Guías SERP: cómo usar, científica vs básica, seno/coseno/tangente, notación científica
- SEO técnico: sitemap index, robots Content-Signal, FAQ/HowTo/SoftwareApplication

## Desarrollo

```bash
npm install
npm run dev
```
